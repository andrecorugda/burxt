Reference Refuses Examples Install GitHub {%- comment -%} The ecosystem, as WORDMARKS rather than words. The `b` in each is Burxt's own logo doing duty as the letter — `[b]mx` and `star-[b]` — which is the whole of the branding decision: a subproject is not a separate identity with a family resemblance, it is this letter inside its own name. So there is no second icon set for them here: a wordmark carries a NAME, and a navbar carries names. Their file-type icons are a different job and live in `assets/subprojects/` — a document with the b for `.bmx`, a gear with the b for `.sbmx`. **The bare `b` belongs to Burxt alone**, since a file tree showing three bare b's would say the three things are the same thing. {%- endcomment -%}
